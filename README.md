# Dyadyami Studio

A premium, cinematic, and immersive studio website built with Next.js 15, React Three Fiber, and GSAP. Designed for high-end brands that demand a sophisticated digital presence.

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **3D Engine**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) & [Three.js](https://threejs.org/)
- **Animations**: [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: [Geist Sans](https://vercel.com/font)

## ✨ Key Features

- **Immersive Hero**: A full-screen WebGL scene featuring floating architectural fragments, dynamic particles, and cinematic post-processing (Bloom, Noise, Vignette).
- **Interactive Experience**: Smooth mouse parallax and scroll-controlled 3D camera movement.
- **Premium Aesthetics**: Deep dark theme (#050505) with luxurious gold accents (#D4AF37) and high-contrast Geist typography.
- **Cinematic Animations**: Scroll-triggered text reveals and smooth transition effects powered by GSAP ScrollTrigger.
- **Responsive Design**: Fully optimized for a premium experience across all device sizes.
- **Interactive Contact Form**: Custom-built UI form with smooth state transitions and animations.

## 📁 Project Structure

- `src/app`: Next.js App Router pages and global styles.
- `src/components/hero`: 3D Scene and Hero section components.
- `src/components/sections`: Content sections (Work, Philosophy, Services, Contact).
- `src/components/layout`: Navigation, Footer, and Smooth Scroll wrappers.
- `src/lib`: Utility functions and shared helpers.
